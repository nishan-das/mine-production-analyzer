# Mine Production & Equipment Performance Analyzer

A Python tool that turns daily mine shift-log data into fleet performance metrics and flags underperforming equipment.

> **All data in this project is synthetic** (generated by `generate_shift_logs.py`). It does not represent any real mine, company or machine.
> Built as a learning project with the help of an AI coding assistant.

## What it computes

For each machine over a month of shift logs (10-machine fleet: 2 shovels, 7 dumpers, 1 dozer):

| Metric | Formula |
| --- | --- |
| Physical availability (%) | (scheduled − downtime) / scheduled |
| Utilisation of availability (%) | operating / (scheduled − downtime) |
| Effective utilisation (%) | operating / scheduled |
| Downtime (%) | downtime / scheduled |
| Productivity (t/h) | tonnes / operating hours |
| Specific fuel consumption (L/t) | litres / tonnes |

Every scheduled hour falls into exactly one bucket: **scheduled = downtime + operating + idle**. Ratios are computed from monthly totals, not by averaging per-shift percentages.

## Data problems it handles

Real shift logs are messy, so the generator plants some problems on purpose:

- blank production or fuel cells → treated as "not recorded", not zero
- shifts where operating + downtime > scheduled hours → flagged and excluded
- zero-division cases (e.g. no operating hours, dozers with no tonnes) → handled by one `safe_divide()` function

## Sample result (synthetic June 2026 data)

| Machine | Physical availability % | Effective utilisation % | Downtime % | Flag |
| --- | --- | --- | --- | --- |
| DT-04 | 61.9 | 52.6 | 38.1 | low availability – maintenance issue; high downtime |
| DT-07 | 95.0 | 64.5 | 5.0 | fit to work but under-used – check dispatch/operators |
| Other dumpers | 93–96 | 84–87 | 4–7 | OK |

The two flagged machines need **different** actions: DT-04 is a maintenance problem, while DT-07 is healthy but idle (a dispatch or operator-availability problem). Targets (85 % availability, 70 % utilisation, 15 % downtime) are illustrative only; each mine sets its own.

## Files

| File | Purpose |
| --- | --- |
| `v1_single_machine.py` | Version 1: one machine, one day, values typed in by hand |
| `generate_shift_logs.py` | Creates `data/shift_logs.csv` (30 days × 3 shifts × 10 machines, synthetic) |
| `fleet_analyzer.py` | Version 2: pandas analysis of the whole fleet; writes `outputs/fleet_kpis.csv` and two charts |

## How to run

```bash
pip install -r requirements.txt
python generate_shift_logs.py
python fleet_analyzer.py
# optional: the original single-machine version
python v1_single_machine.py
```

Outputs: `outputs/fleet_kpis.csv`, `outputs/daily_production.png`, `outputs/equipment_comparison.png`.
